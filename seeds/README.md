# Saved seeds

A seed only reproduces the same world with the **same Tectonic config** (and the same worldgen mods).
Each seed lists the config snapshot it was found with. To restore one, copy that snapshot over
`pack/config/tectonic.json` (and the test server's `config/tectonic.json`), then create a world with the seed.
